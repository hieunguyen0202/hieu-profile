    Chương 17: File Upload

    Upload không phải “lưu file”. Đó là parser, thumbnail, và chỗ execute nếu nhầm path.

    Tác giả: Hieu Nguyen (Ryan) Phần: V — Server-side Cập nhật: Aug 2026

    Khái niệm

    Rủi ro: extension kép, MIME do client, file polyglot, path traversal tên file, store trên origin executable (PHP trong webroot), XXE/image magick.

    Phòng chống

    • Allowlist MIME + magic bytes server-side.
    • Tên file random; không dùng tên user làm path.
    • Store object storage, không webroot.
    • Serve với Content-Disposition attachment + nosniff.
    • Giới hạn size; quét malware trên async worker.
    • Resize ảnh bằng lib an toàn, patch ImageMagick.

    Góc nhìn DevOps

    Bucket private + signed URL. CDN không execute. Pod upload không quyền write trừ volume dedicated.

    Tóm tắt

    • Đừng tin extension client.
    • Object storage.
    • Không execute upload.
    • Signed URL.

    Câu hỏi ôn tập

    1. Content-Type từ browser đủ không?
    2. Vì sao cấm lưu dưới /static user?
    3. Polyglot là gì?
    4. nosniff giúp gì?
    5. Lambda/worker scan virus đặt đâu?
