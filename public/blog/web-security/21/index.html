    Chương 21: Business Logic

    Mọi scanner xanh. Workflow vẫn sai: giá âm, bước nhảy, hoàn tiền kép.

    Tác giả: Hieu Nguyen (Ryan) Phần: V — Server-side Cập nhật: Aug 2026

    Khái niệm

    Lỗ logic: đúng auth nhưng sai luật nghiệp vụ — đổi giá client-side, skip bước verify, voucher stack. Không có CVE chung; cần threat model.

    Phòng chống

    • Giá / role / hạn mức chỉ tin server.
    • State machine đơn hàng: transition hợp lệ.
    • Giới hạn abuse (số lần trial).
    • Test negative: bước 3 không gọi khi chưa bước 2.

    Góc nhìn DevOps

    Feature flag không thay validation. Log business event (refund, role change). Rate-limit API tiền.

    Tóm tắt

    • Server là nguồn sự thật.
    • State machine.
    • Test abuse.
    • Log nghiệp vụ.

    Câu hỏi ôn tập

    1. Vì sao DAST bỏ sót logic?
    2. Giá trên JSON client sai chỗ nào?
    3. Voucher stacking là lớp gì?
    4. Event refund nên log field nào?
    5. Rate-limit khác authz?
