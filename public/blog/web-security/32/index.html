    Chương 32: Cloud Security liên quan web

    IMDS, IAM *, bucket public — web app chỉ là client của cloud API.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    IMDS và credential

    SSRF + IMDS = key node. Bật IMDSv2, hop limit, deny metadata từ Pod.

    IAM

    Không * trên prod role. IRSA/Workload Identity thay key file. Boundary + deny IAM create.

    Object storage

    Block public ACL; policy; encryption; access log. Static site bucket ≠ backup bucket.

    Checklist nhanh

    • WAF + TLS + Shield/Armor tùy cloud.
    • SG/NACL: DB không 0.0.0.0/0.
    • CloudTrail/Activity log bật.
    • Secret manager, không plaintext VM.

    Tóm tắt

    • IMDSv2.
    • Least privilege IAM.
    • Bucket không public mặc định.
    • Audit cloud API.

    Câu hỏi ôn tập

    1. IMDSv2 khác v1?
    2. IRSA tránh được gì?
    3. Public list bucket hại gì?
    4. CloudTrail dùng IR?
    5. WAF thay IAM?
