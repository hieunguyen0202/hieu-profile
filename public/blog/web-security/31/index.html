    Chương 31: Secrets Management

    Secret trong Git là incident đã xảy ra, chưa bị khai thác thôi.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    Khái niệm

    Secret: key, token, cert, mật khẩu. Vòng đời: tạo, phân phối, rotate, revoke, audit.

    Scanning

    gitleaks/trufflehog trên pre-commit + CI + lịch sử. Rotate ngay khi lộ.

    Công cụ

    • Vault / cloud secret manager: dynamic DB creds.
    • External Secrets Operator: sync vào K8s Secret đã mã hóa rest.
    • Sealed Secrets: chỉ nếu hiểu model giải mã.

    Best practices

    • Không env trên frontend.
    • Rotate + dual-run.
    • Audit who read.
    • Tách secret per env.

    Tóm tắt

    • Scan Git.
    • Central manager.
    • Rotate.
    • Audit access.

    Câu hỏi ôn tập

    1. Phát hiện secret Git lúc nào là trễ?
    2. Dynamic secret hơn static?
    3. ESO giải quyết gì?
    4. K8s Secret etcd plaintext khi nào?
    5. Frontend env NEXT_PUBLIC_ chứa gì thì sai?
