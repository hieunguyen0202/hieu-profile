    Chương 29: Kubernetes Security liên quan web

    Ingress, SA token, secret env, NetworkPolicy — web bug đội cánh cluster.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    Khái niệm

    Web app trên K8s thừa attack surface: API server, etcd, IMDS, sidecar. Control cluster là hàng rào khi app lỗi.

    Ingress

    • TLS, security headers (Chương 2).
    • Không expose dashboard / admin.
    • snippet annotation cẩn thận (inject config).

    SSRF tới Kubernetes API

    Pod có SA token mặc định + SSRF = gọi API. Tắt automount; RBAC hẹp; egress deny API.

    Secrets

    Không env nếu có thể (còn dump /proc). Volume file + KMS encryption etcd. Không secret trong image/Helm default.

    Pod Security

    restricted PSS: non-root, drop caps, no priv-esc, seccomp. Policy namespace.

    NetworkPolicy

    Default deny ingress/egress; allow DNS + DB + IdP.

    Image

    Digest pin, scan CI, distroless, không latest.

    Tóm tắt

    • Không automount SA.
    • PSS restricted.
    • NP default deny.
    • Secret không plaintext Git.

    Câu hỏi ôn tập

    1. Automount SA + SSRF?
    2. PSS restricted cấm gì?
    3. Env secret lộ đường nào?
    4. Ingress snippet rủi ro?
    5. Pin digest khác tag?
