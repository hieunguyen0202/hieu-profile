    Chương 35: Checklist bảo mật cho DevOps

    Một trang trước mỗi deploy. Không thay threat model, nhưng bắt được 80% sơ suất.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    Deploy / app

    • TLS + HSTS + headers Chương 2.
    • Cookie flags.
    • Không secret Git.
    • Authz server-side; không admin public.
    • Rate-limit login/API tiền.
    • CORS allowlist.
    • DB bind param + role hẹp.

    Container / K8s

    • PSS restricted.
    • NP default deny.
    • SA không automount.
    • Image digest + scan.
    • Resource limit.
    • readOnlyRootFS khi được.
    • Secret KMS.

    CI/CD

    • SCA/SAST gate.
    • Pin actions.
    • OIDC cloud.
    • Signed artifact.
    • Không secret log.
    • DAST staging.

    Monitoring

    • Auth + 403 + WAF log.
    • Alert spray / 500 / egress lạ.
    • Backup restore đã test.
    • On-call runbook IR.

    Tóm tắt

    • Headers + TLS.
    • PSS + NP.
    • Scan gate.
    • Log/alert/IR.
