    Chương 15: SSRF

    Server đi fetch URL hộ user. Cloud metadata và Kubernetes API ở ngay góc mạng đó.

    Tác giả: Hieu Nguyen (Ryan) Phần: V — Server-side Cập nhật: Aug 2026

    Khái niệm

    SSRF: app mở kết nối tới URL attacker chỉ định (webhook, preview, import). Mục tiêu: localhost, RFC1918, IMDS 169.254.169.254, kube API.

    Phòng chống

    • Allowlist scheme + host; DNS rebinding: resolve rồi khóa IP, cấm redirect lệch.
    • Không tin URL user cho file://.
    • IMDS v2 / hop-limit; NetworkPolicy deny metadata.
    • Webhook: IP allowlist customer, không server-side fetch tùy ý.

    Góc nhìn DevOps

    Đây là chương DevOps. Egress mặc định deny. ServiceAccount token không automount. Split webhook worker ra network riêng.

    Tóm tắt

    • Allowlist URL.
    • Chặn IMDS.
    • Egress deny.
    • Không automount SA.

    Câu hỏi ôn tập

    1. IMDS liên quan SSRF thế nào?
    2. DNS rebinding phá allowlist host ra sao?
    3. Hop-limit IMDS giúp gì?
    4. Webhook nên validate gì?
    5. Kube API từ Pod app: control nào?
