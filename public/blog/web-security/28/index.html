    Chương 28: API Security

    OWASP API Top 10: object authz, mass assignment, rate-limit, version already-dead.

    Tác giả: Hieu Nguyen (Ryan) Phần: VII — API Cập nhật: Aug 2026

    Khái niệm

    API không HTML — CSRF cookie khác, BOLA (IDOR) là số 1. Auth: token, mTLS service-to-service.

    BOLA / object authz

    Giống Chương 6: mọi GET/PATCH theo id phải check sở hữu.

    Mass assignment

    Bind JSON thẳng vào model: client gửi role/balance. Allowlist field.

    Rate limiting

    Theo user + IP + cost. 429 + backoff. Trên gateway và app.

    Versioning

    v1 không vá vẫn live. Sunset header; tắt path cũ trên Ingress.

    Góc nhìn DevOps

    API gateway: JWT, quota, schema validation. OpenAPI làm contract test. Không public swagger prod nếu không cần.

    Tóm tắt

    • Object-level authz.
    • Allowlist field.
    • Quota.
    • Tắt API già.

    Câu hỏi ôn tập

    1. BOLA là gì?
    2. Mass assignment ví dụ field?
    3. 429 nên kèm gì?
    4. Swagger public rủi ro?
    5. mTLS dùng khi nào?
