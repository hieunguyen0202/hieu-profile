    Chương 33: Logging và Detection

    A09: không log thì không incident — chỉ có tin đồn.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    What to log

    • Authn: success/fail/MFA/reset, id, IP, UA.
    • Authz deny (403) với object id.
    • Admin / money actions.
    • 4xx/5xx spike, WAF block.
    • K8s audit: secret get, rbac bind.

    Không log

    Password, cookie, Authorization, card, token query. Mask. Retention và mã hóa at rest.

    Detection

    • Spray: fail login nhiều user một IP.
    • IDOR: 403/200 xen kẽ cùng user khác id.
    • SSRF: app gọi 169.254.
    • Privilege: RoleBinding cluster-admin.

    Stack

    OTLP/Loki/ELK + alert. Pipeline parse JSON structured. Time sync NTP.

    Tóm tắt

    • Structured log.
    • Không secret.
    • Alert abuse.
    • K8s audit song song app.

    Câu hỏi ôn tập

    1. Field auth nên có?
    2. Vì sao không log Authorization?
    3. Spray vs brute một user?
    4. Audit Secret get?
    5. Retention vs forensic?
