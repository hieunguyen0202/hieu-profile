    Chương 16: XXE

    Parser XML mặc định hay tải entity ngoài. Đó là SSRF/file read núp sau SOAP/upload.

    Tác giả: Hieu Nguyen (Ryan) Phần: IV — Injection Cập nhật: Aug 2026

    Khái niệm

    XXE: XML khai entity trỏ file local hoặc URL. Parser resolve → đọc file hoặc gọi nội bộ (SSRF). Hay gặp SOAP, Office XML, SAML, upload “document”.

    Phòng chống

    • Tắt DTD / external entity trên parser.
    • Không parse XML nếu API nhận JSON.
    • Limit size; không follow HTTP entity.
    • Content-Type: đừng parse XML khi client gửi nhầm.

    Góc nhìn DevOps

    WAF có rule XXE — phụ. Image libxml phiên bản còn hỗ trợ. NetworkPolicy chặn Pod app gọi metadata/IMDS.

    Tóm tắt

    • Disable external entity.
    • Prefer JSON.
    • Giới hạn parser.
    • Egress siết.

    Câu hỏi ôn tập

    1. XXE dẫn tới class lỗ nào khác?
    2. SAML/SOAP vì sao hay dính?
    3. Tắt DTD ở đâu?
    4. Upload docx liên quan gì?
    5. Parser default-safe hay default-mở?
