    Chương 18: Path Traversal

    Ghép path từ user rồi đọc file. Dấu chấm chấm vẫn là bug 30 năm.

    Tác giả: Hieu Nguyen (Ryan) Phần: V — Server-side Cập nhật: Aug 2026

    Khái niệm

    Input ../ hoặc encoding đi ra ngoài thư mục cho phép. Ảnh hưởng read file config, key, hoặc ghi đè.

    Phòng chống

    • Không ghép path user; dùng ID → object key map.
    • Canonicalize rồi kiểm tra prefix nằm trong root.
    • OS allowlist filename charset.
    • Least privilege FS; không chạy root.

    Góc nhìn DevOps

    readOnlyRootFilesystem; volume chỉ data dir. Secret không mount vào chỗ app “download template”.

    Tóm tắt

    • Map ID → file.
    • Canonical path check.
    • FS hẹp.
    • Không tin encoding một lần.

    Câu hỏi ôn tập

    1. Canonicalize giải quyết gì?
    2. URL encoding traversal né filter thế nào (ý tưởng)?
    3. Object storage key user-controlled rủi ro?
    4. readOnlyRootFS đủ không?
    5. Log path đã resolve để làm gì?
