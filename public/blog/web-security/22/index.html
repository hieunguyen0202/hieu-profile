    Chương 22: Clickjacking

    User nghĩ đang bấm trang bạn. Thực ra bấm nút trong iframe trong suốt.

    Tác giả: Hieu Nguyen (Ryan) Phần: III — Client-side Cập nhật: Aug 2026

    Khái niệm

    Trang độc hại nhúng app trong iframe, overlay UI. Cú click “trúng” Transfer / Grant permission.

    Phòng chống

    • Content-Security-Policy: frame-ancestors 'none' (hoặc self).
    • X-Frame-Options: DENY / SAMEORIGIN cho client cũ.
    • Không dựa JS frame-busting làm control chính.

    Góc nhìn DevOps

    Header tại Ingress cho mọi response HTML. App cần nhúng (widget) thì allowlist ancestor, không mở hết.

    Tóm tắt

    • Cấm embed mặc định.
    • frame-ancestors hơn XFO.
    • Ngoại lệ widget phải hẹp.

    Câu hỏi ôn tập

    1. Clickjacking cần XSS không?
    2. frame-ancestors khác XFO?
    3. Widget chat nên allow ancestor thế nào?
    4. Header này đặt ở CDN có đủ?
    5. UI confirm có thay clickjacking defense không?
