    Chương 30: CI/CD Security

    Pipeline là production. Ai push YAML là ai ship code lên cluster.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    Khái niệm

    CI/CD đọc PR, secret cloud, deploy. Lỗ pipeline = lỗ prod.

    Rủi ro

    • Script inj từ tên nhánh / PR untrusted (script injection).
    • Dependency confusion: package nội bộ bị cướp tên public.
    • Secret trong log / variable unmasked.
    • Supply chain: action/tag GitHub không pin hash.
    • Self-hosted runner không isolate.

    SAST / DAST / SCA

    SCA sớm (Trivy/Snyk). SAST PR. DAST staging. Fail build mức critical có SLA.

    Phòng chống

    • Least privilege OIDC to cloud, không long-lived key.
    • Pin actions SHA.
    • Tách privileged pipeline.
    • Signed artifact + admission verify.

    Tóm tắt

    • Pin dependencies/actions.
    • OIDC ngắn hạn.
    • Không secret log.
    • Gate scan.

    Câu hỏi ôn tập

    1. Dependency confusion?
    2. Vì sao pin SHA action?
    3. OIDC hơn static key?
    4. DAST chạy đâu?
    5. PR từ fork chạy privileged job sai chỗ nào?
