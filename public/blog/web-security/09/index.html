    Chương 9: CORS

    CORS không phải firewall. Nó là ngoại lệ có kiểm soát của Same-Origin Policy.

    Tác giả: Hieu Nguyen (Ryan) Phần: III — Client-side Cập nhật: Aug 2026

    Khái niệm

    Same-Origin Policy: origin = scheme + host + port. JS origin A không đọc response origin B trừ khi B gửi CORS header cho phép.

    Misconfiguration

    • Phản chiếu mọi Origin kèm Access-Control-Allow-Credentials: true.
    • Whitelist regex sai (evilcompany.com khớp company.com).
    • Cho null origin (sandbox iframe).
    • Wildcard * với credential — browser từ chối; đừng “sửa” bằng reflect origin.

    Phòng chống

    • Allowlist origin chính xác.
    • API cookie: SameSite + CORS chặt, hoặc tốt hơn: bearer token không dựa cookie cross-origin.
    • Preflight: method/header tối thiểu.

    Góc nhìn DevOps

    Header CORS ở Ingress hay app — một nguồn. Đừng add_header ACAO $http_origin vô điều kiện. Review Helm values cors.origin: '*'.

    Tóm tắt

    • SOP mặc định chặn đọc cross-origin.
    • Reflect Origin + credential = hỏng.
    • Allowlist exact.
    • Ingress đừng copy Origin mù.

    Câu hỏi ôn tập

    1. Origin gồm gì?
    2. Vì sao * + credentials không “mở cho tiện”?
    3. null origin đến từ đâu?
    4. Preflight OPTIONS lộ gì?
    5. CORS có chặn request server-side (curl) không?
