    Chương 26: Insecure Deserialization

    Unpickle / Java gadget / PHP unserialize từ dữ liệu user. Object thành code path.

    Tác giả: Hieu Nguyen (Ryan) Phần: V — Server-side Cập nhật: Aug 2026

    Khái niệm

    Deserialize dữ liệu không tin được có thể gọi constructor/magic và gadget chain. Cookie PHP serialized, Java session, Python pickle, YAML load — cùng lớp.

    Phòng chống

    • JSON schema, không pickle/unserialize user.
    • Nếu bắt buộc: chữ ký + allowlist class.
    • Thư viện YAML safe load.
    • Tách network service deserialize.

    Góc nhìn DevOps

    Redis/session không nhận blob lạ từ client. Dependency gadget: SCA. Runtime: non-root.

    Tóm tắt

    • Đừng deserialize input thô.
    • JSON + schema.
    • SCA gadget.
    • Ký blob nếu bắt buộc.

    Câu hỏi ôn tập

    1. Pickle khác JSON chỗ nào?
    2. Cookie serialized PHP rủi ro?
    3. safe_load YAML?
    4. Gadget chain nghĩa là gì (ý tưởng)?
    5. Session store tin client blob khi nào sai?
