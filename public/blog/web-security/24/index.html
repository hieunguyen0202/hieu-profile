    Chương 24: HTTP Request Smuggling

    Front-end và back-end bất đồng CL vs TE. Request của bạn dính request người sau.

    Tác giả: Hieu Nguyen (Ryan) Phần: VI — Infra Cập nhật: Aug 2026

    Khái niệm

    Smuggling khi proxy và origin parse ranh giới request khác nhau (Content-Length vs Transfer-Encoding, HTTP/2 downgrade). Hậu quả: cache poison, bypass WAF, bắt request khác. Khai thác cụ thể chỉ trên lab được phép.

    Phòng chống

    • Cùng HTTP version end-to-end khi được (h2c cẩn thận).
    • Tắt TE trên hop không cần; normalize request ở một chỗ.
    • Cập nhật Nginx/Envoy/Ingress — bug parser là CVE.
    • WAF và origin cùng cách đếm body.

    Góc nhìn DevOps

    Đây là lỗ hạ tầng. Patch Ingress. Không mix custom proxy tự viết. HTTP/2 chỉ terminate một lớp rồi h2 hoặc h1 thống nhất phía sau.

    Tóm tắt

    • Một parser chuẩn.
    • Patch proxy.
    • Đừng tự ghép CL+TE.
    • Lab, không production probing mù.

    Câu hỏi ôn tập

    1. CL vs TE bất đồng gây gì?
    2. Vì sao HTTP/2 downgrade liên quan?
    3. Ai chịu patch?
    4. WAF bypass ý tưởng (không PoC)?
    5. Normalize request nghĩa là gì?
