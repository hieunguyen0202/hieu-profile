    Chương 34: Incident Response cơ bản

    Runbook trước 3 giờ sáng. Không improvisation trên prod đang chảy máu.

    Tác giả: Hieu Nguyen (Ryan) Phần: VIII — DevOps Cập nhật: Aug 2026

    Lifecycle

    Prepare → Detect → Contain → Eradicate → Recover → Lessons. Prepare là exercise + quyền break-glass.

    Detection

    Alert Chương 33. On-call biết dashboard. Severity: data leak / RCE / deface khác SLA.

    Containment

    • Cắt Ingress / scale 0 / NP deny.
    • Rotate secret + session invalidate.
    • Isolate namespace.
    • Không xóa log/pod trước khi snapshot.

    Forensics tối thiểu

    Timeline log, kubectl describe/events, image digest đang chạy, audit API. Snapshot volume nếu cần. Chuỗi custody nội bộ.

    Communication

    Kênh riêng, pháp chế nếu PII. Không tweet root cause sớm. Status page sự thật.

    Post-mortem

    Blameless: timeline, gap control, ticket vá, game-day.

    Tóm tắt

    • Prepare.
    • Contain trước forensics đầy đủ.
    • Rotate.
    • Học ra ticket.

    Câu hỏi ôn tập

    1. Contain khác eradicate?
    2. Vì sao không xóa Pod ngay?
    3. Break-glass account?
    4. Ai nói với khách?
    5. Metric thành công IR?
