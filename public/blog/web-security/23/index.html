    Chương 23: Web Cache Poisoning

    Cache nhớ response theo key sai. Một header độc hại thành trang của mọi user.

    Tác giả: Hieu Nguyen (Ryan) Phần: VI — Infra Cập nhật: Aug 2026

    Khái niệm

    CDN/Varnish key thường Host + path. Header/query không nằm trong key nhưng làm đổi body → poison. Unkeyed header (X-Forwarded-Host, malformed Accept) hay gặp.

    Phòng chống

    • Cache key gồm mọi input ảnh hưởng response.
    • Không tin Host/XFH chưa allowlist (Chương 2).
    • Tách cache cookie-personalized vs static.
    • Normalize URL; không cache response lỗi lạ.

    Góc nhìn DevOps

    Cloudflare/Fastly cache rules là production. Review “cache everything”. Purge khi incident. Vary header đúng.

    Tóm tắt

    • Key = mọi input ảnh hưởng body.
    • Allowlist Host.
    • Đừng cache HTML cá nhân hóa như static.
    • Purge playbook.

    Câu hỏi ôn tập

    1. Unkeyed header là gì?
    2. X-Forwarded-Host liên quan poison?
    3. Vary dùng để làm gì?
    4. Cache everything trên HTML login?
    5. Poison khác XSS stored chỗ nào?
